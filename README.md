## ⚡ Quick Start (Global Installation)

Install this plugin globally into your Antigravity environment (`~/.gemini/config/plugins/`) with a single command:

```bash
curl -fsSL https://raw.githubusercontent.com/YOUR_USERNAME/antigravity-claude-skills/main/install.sh | bash
```

Or clone and link it manually:

```bash
git clone https://github.com/SANOOPKCT/antigravity-claude-skills.git ~/.gemini/config/plugins/antigravity-claude-skills
```

Once installed, all 67 skills are **instantly active** across all your projects and workspaces. No restart required!

## 🎮 How to Use in Antigravity

Antigravity features **progressive disclosure**. This means skills don't clutter your context window until they are relevant:

1. **Via `/` Prompt Suggestions**:
   Type `/` in the Antigravity chat input to view suggested workflows or enter prompts like:
   - `/` or `/fastapi-expert`
   - `/react-expert`
   - `/kubernetes-specialist`

2. **Via Natural Conversation**:
   The agent automatically detects the skill needed based on your question:
   - *"Design an enterprise Next.js App Router architecture with server components."*
   - *"Audit my code for OWASP Top 10 vulnerabilities."*
   - *"Tune my PostgreSQL queries and suggest missing B-tree indexes."*
   - *"Write a Kubernetes Helm chart with HPA and PodDisruptionBudget."*
